# SwiftDevProjects

A personal portfolio repository containing a collection of iOS applications and Swift playgrounds. I created these projects while **independently learning Swift and iOS App Development**. This repository tracks my journey from basic Swift syntax to building fully functional, interactive iOS applications.

## 🚀 Learning Journey & Projects

The repository is structured to reflect progressive learning, starting from basic language constructs and moving toward complex iOS frameworks.

### 1. Swift Basics (Playgrounds)
Interactive Xcode Playgrounds used to master the core concepts of the Swift programming language:
- `variables.playground` - Variables, Constants, and Data Types.
- `Arrays.playground` - Collections, Arrays, and Dictionaries.
- `IfControl.playground` - Control Flow and Conditionals.
- `Loops.playground` - For, While, and Repeat-While loops.
- `Functions.playground` - Methods, Parameters, and Return types.
- `Optionals.playground` - Safe handling of null values (Optionals, unwrap, guard let).

### 2. UI & Core App Components
Mini-applications built to understand the iOS UI lifecycle, Auto Layout, and basic user interactions:
- **Calculator**: A fully functional calculator demonstrating basic UI components and math logic.
- **FirstApp** & **ProjectLayout**: Understanding Storyboards, ViewControllers, and Auto Layout constraints.
- **ObjectsWithCode**: Building user interfaces programmatically without Storyboards.
- **AlertProject**: Implementing `UIAlertController` for pop-ups and user feedback.

### 3. Navigation & Data Passing
- **SegueApp**: Learning how to navigate between multiple screens and pass data between ViewControllers.
- **GestureRecognizerApp**: Adding tap, swipe, and interactable gestures to UI elements.

### 4. Data Storage & Persistence
- **BirthdayNoteTaker**: Using `UserDefaults` to save lightweight, persistent local data.
- **ArtBook**: A more advanced local database app using **Core Data** to save images and text persistently.

### 5. TableViews & Lists
- **LandmarkBook** & **SimpsonBookApp**: Applications demonstrating how to use `UITableView` to display dynamic lists of data, custom cells, and navigation to detail views.

### 6. Timers & Games
- **TimerProject**: Implementing `Timer` to trigger events at specified intervals.
- **CatchKenny / CatchTheKennyGame**: A fun, interactive game built using Timers, Random number generators, and Gesture Recognizers.

### 7. Advanced Integration
- **SocialMediaApp**: A more complex application demonstrating backend integration (e.g., Firebase) for user authentication, posting, and fetching dynamic data.

## 🛠 Technologies & Frameworks Used

- **Language**: Swift 5+
- **IDE**: Xcode
- **UI Frameworks**: UIKit, Storyboards, Programmatic UI
- **Storage**: Core Data, UserDefaults
- **Key Concepts**: OOP (Object-Oriented Programming), MVC (Model-View-Controller) Architecture, Optionals, Delegation, Segues.

## 💡 Purpose

This repository is strictly a **personal learning archive**. It serves as a reference for the fundamentals of Swift and iOS development, and stands as a showcase of my personal growth as an iOS Developer.

## 📥 How to Run

To run any of these projects:
1. Clone this repository: `git clone https://github.com/semihgny/SwiftDevProjects.git`
2. Open the respective `.xcodeproj` or `.xcworkspace` file in **Xcode**.
3. Select an iOS Simulator (or your connected device).
4. Hit `Cmd + R` to build and run.
